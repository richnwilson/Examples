"# Slackbot" 

#Setup
1. Login to api.slack.com/apps
2. Create a New App
3. Give it a suitable name and use the 'IBM Academy of Technology' workspace
4. In the 'Add features and functionality',  click Bots and 'Add a bot User'
5. Don't check box to show always online
6. Create and save and then move back to Settings > Basic Information
7. Click on Install your app to your workspace and authorize
8. If necessary, move down and add description, icon and background color and then save changes
8. To grab the token you'll need in the code, go to Features > OAuth & Permissions and copy the 'Bot User OAuth Access Token'
9. Install slackbots and axios libraries for node and build the code
